# 🧠 Enterprise RAG System

An AI-powered **Retrieval-Augmented Generation (RAG)** application built using **Python, Streamlit, AWS Bedrock, and Amazon S3**.  
The system allows users to upload enterprise documents and ask questions in natural language with citation-based AI responses.

## 🚀 Features

- 📄 Upload PDF, DOCX, TXT documents
- 🤖 AI-powered enterprise chatbot
- ☁️ Amazon S3 document storage
- 📚 AWS Bedrock Knowledge Base integration
- 📌 Citation-supported answers
- ⚡ Streamlit-based interactive UI

## 🛠️ Tech Stack

- Python
- Streamlit
- AWS Bedrock
- Amazon S3
- Boto3
